# Job Portal with Employer Dashboard

## 📘 Description
This project is a **web‑based recruitment and employment management system** built using **Java (Spring Boot)** for the backend and **React** for the frontend.  
It provides a centralized platform where employers can post jobs, job seekers can apply, and administrators can manage the entire process efficiently.

## 🎯 Objective
To simplify the hiring process by connecting employers and job seekers through a single portal, offering transparency, easy tracking, and secure data management.

## 👥 Users & Roles
- **Admin** – Manages users, employers, and job postings.  
- **Employer** – Posts jobs, manages company profile, and reviews applicants.  
- **Job Seeker** – Searches for jobs, uploads resume, and applies for jobs.

## 🗂️ Core Entities / Database Tables
Users | Employers | JobSeekers | Jobs | Applications | Resumes | Companies | Categories

## 🧠 Tech Stack
- **Frontend:** React  
- **Backend:** Java (Spring Boot)  
- **Database:** MySQL  
- **Version Control:** Git + GitHub

## 🚀 Features
- Employer dashboard for job management  
- Job seeker portal for applications  
- Admin panel for monitoring and reports  
- Secure authentication and role‑based access  

## 🧩 Domain
Web Application / Recruitment & Employment Management
